### Added

- Umbrella package for 72 Journey to Code ecosystem packages.
- Root namespace exports for every included package.
- Category exports for text, arrays, objects, async, dates, math, data, encoding,
  validation, web, state, cache, filesystem, color, Markdown, and developer tooling.
- Direct package subpath exports.
- Machine-readable ecosystem manifest.
- Dependency/import verification.
- Import, category, and composition integration tests.
